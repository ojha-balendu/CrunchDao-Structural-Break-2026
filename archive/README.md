# Archive

Older material kept for the record. **None of it is needed to run the current solution**,
which is `submission.ipynb` at the repository root.

| Folder | Contents |
|---|---|
| `notebooks/` | Earlier versions of the main notebook (backups taken before each major change: CatBoost, volatility families, literature families, null model), the CatBoost-free variant, and the September research notebook with the full log of rejected ideas |
| `legacy_scripts/` | Early script conversions of the notebook and a draft of the BOCPD family |
| `refactor_phases/` | The scripted, six-phase refactor of the notebook (registry cull, fast families, fast metrics, per-family cache, research loop, parallel backend), each phase with a test that checks the new code against a frozen copy of the code it replaced. They ran against notebook versions now in `notebooks/` |
| `artifacts/` | An early 82-feature model and a labels file from the 2025 edition of the challenge |
| `misc/` | A file unrelated to this project |
